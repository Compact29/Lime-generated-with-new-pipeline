# figma-site

Generated by Figma Fighter Builder from 1 Figma page.

## Routes

- Home: `/page-1`

## Run

```bash
npm install
npm run dev
npm run build
```

Generated page components live in `src/generated/page_n/` folders.
Figma screenshots, when extraction succeeded, live in `design-reference/`.

## Headless CMS

This project includes a starter Headless CMS scaffold:

- Admin page: `/cms`
- CMS schema: `cms/schema.json`
- JSON database: `cms/db.json`
- Backend API: `cms/backend/server.mjs`
- Frontend helper: `src/cms/cmsClient.js`

Run the frontend and CMS backend in separate terminals:

```bash
npm run dev
npm run cms:server
```
